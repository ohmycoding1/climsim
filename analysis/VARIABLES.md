# ClimSim 변수 참고 (저해상도 v1: 입력 124 / 출력 128)

기후모델은 대기를 **연직 60개 층**으로 나눈다. 층 인덱스는 `0 = 대기 꼭대기(TOA)`,
`59 = 지표면(최하층)` 이다(인덱스가 클수록 지표에 가깝고 기압이 높다). 각 격자에서
"현재 상태(입력)"를 받아 "다음 순간의 변화율(경향, tendency)"과 지표 결과를 출력한다.

## 입력 (124) — 현재 대기 상태 + 외부 강제력

| 인덱스 | 변수명 | 뜻 | 단위 | 특징 |
|---|---|---|---|---|
| 0–59   | `state_t`     | 기온 (60개 층)        | K      | 하층 따뜻·상층 차가움 |
| 60–119 | `state_q0001` | 비습(수증기량, 60개 층) | kg/kg | 하층에 몰리고 상층은 거의 0 |
| 120    | `state_ps`    | 지표 기압             | Pa     | ~100,000, 지형/고도 정보 |
| 121    | `pbuf_SOLIN`  | 들어오는 태양복사(일사) | W/m²   | 낮/밤·위도로 변함, 에너지원 |
| 122    | `pbuf_LHFLX`  | 지표 잠열 플럭스       | W/m²   | 증발(수증기 공급) |
| 123    | `pbuf_SHFLX`  | 지표 현열 플럭스       | W/m²   | 지표가 공기를 데우는 열 |

## 출력 (128) — 다음 순간의 변화율 + 지표 결과

| 인덱스 | 변수명 | 뜻 | 단위 | 예측 난이도 |
|---|---|---|---|---|
| 0–59    | `ptend_t`       | 기온 경향 dT/dt        | K/s      | 중간 |
| 60–119  | `ptend_q0001`   | 수증기 경향 dq/dt      | kg/kg/s  | **가장 어려움** (대류·강수) |
| 120     | `cam_out_NETSW` | 지표 순 단파복사       | W/m²     | 쉬움 |
| 121     | `cam_out_FLWDS` | 지표 하향 장파복사     | W/m²     | 쉬움 |
| 122     | `cam_out_PRECSC`| 눈 강수율             | m/s      | 희소(대체로 0) |
| 123     | `cam_out_PRECC` | 비 강수율(대류성)      | m/s      | 희소·급변 |
| 124     | `cam_out_SOLS`  | 가시광 직달 일사       | W/m²     | 쉬움 |
| 125     | `cam_out_SOLL`  | 근적외 직달 일사       | W/m²     | 쉬움 |
| 126     | `cam_out_SOLSD` | 가시광 산란 일사       | W/m²     | 쉬움 |
| 127     | `cam_out_SOLLD` | 근적외 산란 일사       | W/m²     | 쉬움 |

## 핵심 특징

1. **입력·출력이 쌍을 이룬다**: `state_t → ptend_t`, `state_q0001 → ptend_q0001`.
   현재 상태로부터 그 변화율을 예측한다.
2. **surface 8개(복사·일사)는 쉽다**: 입력(특히 `SOLIN`)과 물리 관계가 직접적이라
   R²가 높다(0.8~0.9). 상층 `ptend_q0001`(≈0)도 사실상 결정론적이다(열 64–71).
3. **`ptend_q0001`(수증기 경향)가 가장 어렵다**: 대류·응결·강수는 국소적이고 급변하는
   "격자 이하(sub-grid)" 현상이라 어떤 모델도 잘 못 맞춘다. 이것이 AI 에뮬레이터의 본질적 난제.

## 물리 기반 파생변수 (feature engineering)의 근거

| 파생변수 | 정의 | 물리적 의미 |
|---|---|---|
| `dT` | `state_t` 층간 차분 | 대기 안정도(lapse rate), 대류 발생 조건 |
| `dq` | `state_q0001` 층간 차분 | 수증기 연직 수렴/발산 |
| `T×q` (층별) | `state_t * state_q0001` | 상대습도 개념(따뜻한 공기가 수증기 더 머금음) |
| 기둥 수증기 | `state_q0001` 연직 평균 | 사용 가능한 총 수분량(가강수량 proxy) |
| 하층/상층 집계 | 하층/상층 평균 | 대류가 일어나는 하층을 강조 |
| `SOLIN×기둥수증기` | 상호작용 | 일사가 습한 공기를 데우는 정도 |
| `LHFLX×하층수증기` | 상호작용 | 증발↔대류 결합 |

주의: `dT`, `dq`, 기둥평균 등은 입력의 **선형 결합**이라 선형모델에는 새 정보가 아니다.
선형모델을 실제로 개선하는 것은 **비선형 상호작용 항**(곱)뿐이다.
